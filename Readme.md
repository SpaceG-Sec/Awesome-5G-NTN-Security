# Awesome-5G-NTN-Security

An open-source, AI-driven security auditing and compliance framework tailored for 3GPP 5G Non-Terrestrial Networks (NTN) and space-based core networks. 

As 5G SA architecture extends into Low Earth Orbit (LEO) satellites, the satellite communication (SatCom) domain is shifting from proprietary protocols to cloud-native stacks (HTTP/2, JSON, REST APIs, and Kubernetes). This paradigm shift opens up space-bound gNodeBs and space-borne core networks to web-centric vulnerabilities. 

`Awesome-5G-NTN-Security` bridges the gap between traditional aerospace engineering and modern DevSecOps. Driven by specialized LLM agents and high-precision RAG, it automates the detection of signaling anomalies, configuration flaws, and compliance gaps across the satellite-ground link.
